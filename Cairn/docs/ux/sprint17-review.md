# UX Review — Sprint 17

**Sprint**: 17
**Date**: 2026-05-15
**Sprint Goal**: Full English UI conversion for NZ/Global market

## Summary

All screens reviewed as a first-time English-speaking user. The product is fully navigable with no Chinese text visible anywhere in the UI flow.

## Screens Reviewed

### Auth Splash
- "Leave a mark. Guide the next." — clear tagline, appropriate for NZ outdoors audience
- "Create Account" and "Sign In" — unambiguous CTAs
- No friction: 0 steps to understand purpose

### Register / Sign In Forms
- Field labels and placeholders fully English
- Privacy Policy checkbox legible
- Social login options ("Continue with Apple/Google") — standard pattern, no confusion

### Home Screen
- "Good evening" greeting — natural English
- Activity cards: "Hiking / Navigate trails · Plant flags · Explore" and "Running / Route planning · Voice guidance · Lock mode" — descriptive, NZ-trail audience appropriate
- Tools section with "Map", "Friends", "Settings" — minimal, clear

### HikingScreen
- "GPS Offline" chip — clear status
- "Start Hiking" CTA — direct
- "Back" chip top-right — easily discoverable

### RunningScreen
- "Running Mode" + "Select a route (optional)" heading — clear intent
- "Free Run / GPS tracking · Any route" — well-labelled
- "Screen locks on start · Double-tap to unlock" hint — important safety info, well-placed below CTA

### MapHistoryScreen
- "Route Map" title + "Plan" action button — clear
- Tab bar: "Route History" / "My Flags" — intuitive segmentation
- Empty state: "No routes yet / Your hikes and runs will appear here" — helpful, not alarming

### FriendsScreen
- "Sharing flags with 3/3 friends" banner — informative at-a-glance status
- Per-friend "Sharing" / "Hidden" toggle labels — clear
- Info box explains sharing behaviour — proactive, reduces confusion

### SettingsScreen
- Section headers uppercase — good visual hierarchy
- Mode card descriptions: "Labels everywhere · Beginner-friendly" vs "Icons only · Minimal" — self-explanatory
- All toggle hints in plain English

## Friction Items

None — Blocker or Critical level. The English conversion is clean and consistent.

**Low (cosmetic)**: SettingsScreen currently defaults to "Simple Mode" selected even though the user is a new account that should default to Guided. This is a pre-existing state issue, not introduced by Sprint 17 English changes.

## Visual Fidelity

No drift from Sprint 0 style direction. Green primary palette, card-based layout, SVG icons throughout — consistent.

## Verdict

**No Blocker or Critical friction items.** Sprint 17 English conversion is complete and user-facing quality is high for an NZ/Global English audience.
